# 作品分享

## 页面简介

这个界面是我作品的分享界面，这里面会列出我已发布的作品。

你可以进入作品列表界面找到作品，可根据媒体平台作品的简介编号进行检索，或者使用搜索功能。

:::info
有些作品可能没有绿幕素材或没有列出，只是因为我没来得及。😴
:::

## 如何下载
网站使用蓝奏云存储分享作品，在检索到想要的作品后通过分享链接即可下载。
::: tip
每部作品至少有原图、发布版本（发布于平台的版本）、和绿幕素材。如果发现没有，那就是正在制作。

绿幕素材的文件名后面会加有“gb”字样，注意区分。
:::
