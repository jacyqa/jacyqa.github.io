# 教程部分
## 前言
这一部分是木偶的教程，讲实话我觉得我的技术算不上多精湛，但还是希望能帮到你！另外我的思路可能和网上看到的有些不同，希望给你带来新的思路。
## 软件及版本
1. After Effects CC 2019
2. Photoshop 2021
3. AutoSwave 1.8.6(AE插件)
:::tip
可能有些同学没有电脑或者实在不想用这些软件，没关系的，重要的是要融会贯通核心要领，在其他类似的软件（如画世界，Nodevideo）也可以实现的！
:::
## 前期准备
**首先**让你的原图足够**清晰**，感觉不够清晰的可以使用超分软件进行处理。另外，原图的人物光环大概率是不全的，可以前往基沃托斯古书馆下载到相关资源。**最后，一颗耐心，这是最重要的，这个过程可能会比你想象的要长，要难，但是不要灰心，相信我，你一定能做到的！**
