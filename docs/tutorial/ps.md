# PS部分
你的图片现在要在PS等图像处理软件中进行拆分与补全的处理，准备好足够清晰的原图，导入PS让我们开始吧！
## 1.分析图片以及你想要的效果
这一步要先整体分析图片，确认原图，猜想原图想要表达的意思是什么，包括那些部分会运动，整体是怎么运动的，甚至是想表达的情绪风格，这些在后续步骤中很有用。
:::tip
在最后调色时尽量保持情绪风格一样。
:::
## 2.进行拆分
这一步就是PS处理的核心了，网上教程是在原图上拆出一部分就补一部分，我建议**先全部拆完**，然后再补，因为PS中的**内容识别填充**功能是基于当前图层识别的，会将自动将补全的部分与已有部分进行融合，这样会更简单，而且不会出现错误。

我一般使用**钢笔**工具进行拆分，当然其他选择工具也是可以的。核心就是将要让拆分的部分被选区框出来就行，然后将选区**以拷贝方式建立新图层**（Ctrl+j），建议及时给新建立的图层进行**具体命名**（如背景、前发、头部等）。例如将人物前发抠出时：
